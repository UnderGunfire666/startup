# startup

`startup` 是一款以城市选址、店铺筹备与日常经营为核心的 Godot 4.7 模拟经营原型。玩家从调查城区开始，发现并尽调门面，签约后配置商品、设备、员工与布局，再通过排班、采购和经营结算逐步扩展品牌。

## 核心循环

`区域调查 → 门面发现/尽调 → 选址签约 → 店铺配置与布局 → 排班采购经营 → 日终结算 → 品牌扩张`

## 当前状态

项目已具备一条可验证的单店经营流程，并已有多店数据模型基础：

- 城市地图、道路图、区块调查、门面发现与完整尽调。
- `CR001` 可玩示例城区：33 个道路节点、50 条道路段、12 个区块、25 个门面。
- 商品、采购库存、设备、员工、排班、时间推进与顾客/经营结算。
- 室内与门面布局的 2D 网格编辑和正交 3D 编辑；两种视图共享同一份布局数据。
- JSON 存档、旧存档兼容迁移，以及覆盖核心领域的 Godot 契约测试。

这仍是原型阶段：布局尚未影响经营效率，门面和设备使用程序化占位表现；不含可编辑墙体、员工寻路、实时交通或完整美术资产。
